## <a id="paralinguistic-tags-new"></a>副语言标签 **新增**

标签可插入中文或英文文本的任意位置。它们会绕过文本归一化，原样传入模型。标签区分大小写，必须保留方括号。

| 标签 | 效果 |
| :--- | :--- |
| `[Breathing]` | 可听见的呼吸声 |
| `[Cough]` | 咳嗽 |
| `[Sigh]` | 叹气 |
| `[Laughter]` | 笑声 |
| `[Uhm]` | 犹豫时的填充音 |
| `[Surprise-ah]` | 惊讶的“啊” |
| `[Surprise-oh]` | 惊讶的“哦” |
| `[Dissatisfaction-hnn]` | 不满的“哼” |
| `[Confirmation-en]` | 肯定的“嗯” |
| `[Question-ei]` | 疑问的“诶” |
| `[Question-ah]` | 疑问的“啊” |
| `[Question-en]` | 疑问的“嗯” |
| `[Question-oh]` | 疑问的“哦” |
| `[Question-huh]` | 疑问的“哈” |

## <a id="target-languages-new"></a>目标语言 **新增**

通过 `language_id` 指定目标语言。中文和英文可以不指定；其余五种语言需要指定，以便在提示词中加入目标语言信息，并绕过中英文文本归一化。

| `language_id` | 语言 |
| :--- | :--- |
| `zh` | 中文 |
| `en` | 英语 |
| `ja` | 日语 |
| `ko` | 韩语 |
| `de` | 德语 |
| `fr` | 法语 |
| `es` | 西班牙语 |

音色由参考音频决定，而非由目标语言决定，因此中文参考音频也可用于合成上述其他语言。

方言不通过此参数选择，请使用下方的 `dialect` 控制参数。

## <a id="freeform"></a>自由指令控制

通过 `instruction` 传入自然语言指令，描述语气、节奏、重音或表达方式；`text` 只填写需要合成的正文，不要把指令拼进正文。无需提供参考音频，默认也不建议添加。不要与音色设计、内置音色、情感、方言或基础属性控制混用。

下表保留实际使用的指令。场景名称仅用于说明，不是模型入参。

| 场景 | 实际使用的指令（`instruction`） |
| :--- | :--- |
| 英文运动教练 | Sound like an encouraging sports coach, energetic and firm without shouting. |
| 中文睡前故事 | 用温柔、舒缓的声音讲述睡前故事，像在轻声安慰孩子。 |
| 英文温暖叙事 | Speak in a warm, intimate storytelling voice, unhurried. |

以下为配套调用示例，假设模型已按 README 加载；合成正文仅作使用演示。

### 英文运动教练（0.5B）

```python
model.synthesize(
    task="FREEFORM",
    text="Keep your eyes forward and your shoulders relaxed. One more round—you can do this!",
    instruction="Sound like an encouraging sports coach, energetic and firm without shouting.",
    use_zero_spk_emb=True,
)
```

### 英文温暖叙事（0.5B）

```python
model.synthesize(
    task="FREEFORM",
    text="The old radio crackled softly as the storm moved across the valley.",
    instruction="Speak in a warm, intimate storytelling voice, unhurried.",
    use_zero_spk_emb=True,
)
```

### 中文睡前故事（Tiny）

不传 `prompt_wav` 和 `prompt_text`。

```python
tts.generate(
    task="freeform",
    text="小熊轻轻闭上眼睛，月亮替它盖好了一床银色的被子。",
    instruction="用温柔、舒缓的声音讲述睡前故事，像在轻声安慰孩子。",
)
```

## <a id="speech-control"></a>语音控制

请原样传入反引号内的参数名和参数值；音色调用名称、情感后缀和行内标签也不要翻译或改写。

| 控制参数 | 可选值 |
| :--- | :--- |
| `emotion` | `高兴`, `悲伤`, `愤怒`, `恐惧`, `厌恶`, `惊讶`, `中性` |
| `dialect` | `cantonese` (粤语), `chuanyu dialect` (川渝话) |
| `speed` | `慢速`, `中速`, `快速` |
| `pitch` | `低`, `中`, `高` |
| `volume` | `低`, `中`, `高` |
